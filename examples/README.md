# Examples

Synthetic snapshots for trying the toolkit without touching a real Data Cloud org.

## `demo-org/`

A fake "AcmeRetail" snapshot: 4 DMOs and 8 CIs engineered to exhibit the patterns the audit and converter catch. Safe to share, demo, screenshot, or record.

### Layout

```
demo-org/
├── object-model/
│   ├── index.yaml                   org metadata (alias, instanceUrl, counts)
│   ├── dmos/                        4 DMOs
│   │   ├── Account__dlm.yaml
│   │   ├── SalesOrder__dlm.yaml
│   │   ├── Individual__dlm.yaml         (ssot__Individual__dlm)
│   │   └── EmailUnsubscribes__dlm.yaml  (Email_Unsubscribes__dlm)
│   └── cis/                         8 CI sidecars (one per SQL file)
├── queries/                         8 hand-written CI SQL files
├── queries-converted/               regenerated by ci_audit.py --fix
└── reports/                         regenerated by audit + dashboard
```

### What each CI demonstrates

| CI | Findings exercised |
|---|---|
| `Active_Customer_Accounts` | hardcoded RecordType ID literal |
| `Birthday_Email_Audience` | `MONTH()/DAY()` leap-year bug; missing unsubscribe LEFT JOIN |
| `New_Account_Welcome` | single-day trigger equality (`= date_add(current_date(), -1)`) |
| `Customer_Order_Summary_QueryEditor` | Query Editor SQL: 3-arg `COALESCE`, `COUNT(DISTINCT)`, `EXTRACT`, DMO aliases, `IN (SELECT col)`, top-level `ORDER BY` |
| `Account_Parent_Hierarchy` | self-join (same DMO twice in one scope) |
| `Order_Conversion_Rate` | `AVG(CASE ...)` nesting; duplicate predicate in JOIN ON and WHERE |
| `Customer_Profile_Score` | derived expression repeated 3+ times (`IFNULL(...)` reused across SELECT / CASE / GROUP BY) |
| `Customer_Order_Totals` | clean baseline — no findings |

### Reproduce the reports

From the repo root, with the venv active:

```bash
# Audit + auto-fix in one shot — writes queries-converted/ and reports/ci-convert.md
python ci_audit.py --output-dir examples/demo-org --fix

# Render the single-page dashboard
python dashboard.py --data-dir examples/demo-org --client AcmeRetail
open examples/demo-org/reports/dashboard.html
```

Expected current totals: **8 auto-fixes, 1 flag, 1 remaining violation** (the engineered self-join, which has no auto-fix — the converter flags it for an upstream pre-build).
